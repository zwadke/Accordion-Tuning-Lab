# Accordion Tuning Lab 3.4 — first public release

A free interactive tool for exploring accordion tuning, tremolo and musette.

- Independent two- and three-reed tuning curves and beating rates
- Accordion-like and sine-wave synthesis
- MIDI input, MIDI file playback and built-in test notes
- Three profile slots and example tuning profiles
- English and Dutch interface

**Windows:** download `Accordion_Tuning_Lab_Setup.exe` below. Python is not required. The installer is unsigned.

See the repository README for documentation and source code.
